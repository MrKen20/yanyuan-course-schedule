## 项目简介

一个纯前端、零依赖、开箱即用的课程表查询工具。数据为虚构演示数据，存储于本地 JS 文件中，不接入任何真实用户数据、不涉及密钥与生产环境。

## 功能特性

- **周视图课程表**：以 7 天 × 6 节次的网格展示整周课程，按教学周自动显示对应课程
- **今日高亮**：自动定位今天所在的列，并显示当前日期与教学周
- **课程搜索**：支持按课程名 / 教师 / 教室模糊搜索，命中课程在表格中金色描边高亮
- **星期切换**：点击星期标签查看任意一天的课程列表（移动端友好）
- **课程详情**：点击课程卡片弹出详情，含时间、地点、教师、类型、周次与备注
- **响应式布局**：小屏幕自动切换为列表视图

## 快速开始

本项目无需任何构建工具或依赖安装，两步即可运行：

1. 克隆仓库：

   ```bash
   git clone <你的仓库地址>
   ```

2. 用浏览器直接打开 `index.html` 即可；或启动一个本地静态服务器：

   ```bash
   # Python
   python -m http.server 8080
   # Node.js
   npx serve .
   ```

   然后访问 `http://localhost:8080`。

## 技术要点

- 语义化 HTML + CSS Grid 实现课程表网格布局
- 原生 JavaScript（IIFE 封装，无全局污染）完成渲染与交互
- 数据与视图分离：课程数据集中在 `js/data.js`，便于维护与扩展
- CSS 变量统一管理主题色，一键换色
- 响应式适配：`@media` 断点下自动隐藏网格、启用列表视图

## 数据说明

`js/data.js` 中的课程信息均为**虚构演示数据**，仅用于课程作业展示，不包含任何真实个人信息。
