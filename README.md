## 项目简介

一个纯前端、零依赖、开箱即用的课程表查询工具，适用于 **2026~2027 学年度第一学期**。数据为虚构演示数据，存储于本地 JS 文件中，不接入任何真实用户数据、不涉及密钥与生产环境。

## 功能特性

- **周视图课程表**：以 7 天 × 12 节次的网格展示整周课程，节次时间严格参照《北京大学 2026-2027 学年上课时间》（校本部）：第 1-4 节为上午、第 5-9 节为下午、第 10-12 节为晚上
- **连堂课程**：支持 2~4 节连堂课（如实践课 4 节连上），课程块自动跨行合并；上午课不跨入下午、下午课不跨入晚上
- **周次切换**：‹ / › 按钮查看任意教学周的课程，按周开课的课程（单周 / 双周 / 前 / 后半学期）随周自动显隐
- **今日高亮**：自动定位今天所在的列，并显示学期、当前日期与教学周
- **课程搜索**：支持按课程名 / 教师 / 教室模糊搜索，命中课程在表格中金色描边高亮
- **星期切换**：点击星期标签查看任意一天的课程列表（移动端友好）
- **课程详情**：点击课程卡片弹出详情，含时间、地点、教师、类型、连堂节数、周次与备注
- **响应式布局**：小屏幕自动切换为列表视图

## 快速开始

本项目无需任何构建工具或依赖安装，两步即可运行：

1. 克隆仓库：

   ```bash
   git clone <你的仓库地址>
   ```

2. 用浏览器直接打开 `index.html` 即可；或启动一个本地静态服务器：

   ```bash
   # Python
   python -m http.server 8080
   # Node.js
   npx serve .
   ```

   然后访问 `http://localhost:8080`。

## 技术要点

- 语义化 HTML + CSS Grid 实现课程表网格布局，连堂课通过 `grid-row: span n` 跨行合并
- 原生 JavaScript（IIFE 封装，无全局污染）完成渲染与交互
- 数据与视图分离：课程数据集中在 `js/data.js`，便于维护与扩展
- CSS 变量统一管理主题色，一键换色
- 响应式适配：`@media` 断点下自动隐藏网格、启用列表视图

## 数据说明

`js/data.js` 中的课程信息均为**虚构演示数据**，仅用于课程作业展示，不包含任何真实个人信息。课程数据结构：

```js
{ day: 4, startPeriod: 5, length: 4, weeks: [4, 6, 8, 10, 12, 14], type: "实践课", ... }
//  周四    第 5 节开始     连上 4 节     双周上课（第 4-14 周）   课程类型
```

课程类型涵盖：专业必修 / 专业选修 / 公共必修 / 通识必修 / 通识选修课 / 思政必修 / 习题课 / 实践课。

节次时间严格参照北大校历（校本部）：上午第 1-4 节（08:00-12:00）、下午第 5-9 节（13:00-18:00）、晚上第 10-12 节（18:40-21:30）；上午课不跨入下午，下午课不跨入晚上。学期信息（2026~2027 学年度第一学期）与节次表统一维护在 `js/data.js` 顶部常量中。
